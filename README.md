### 2번
일단 피보나치 수열이 어떻게 생겼는지 쭉 나열해 보면,

1, 2, 3, 5, 8, 13, ...

과 같이 이어진다.

이때 각 항의 홀짝을 살펴보면,

(홀 / 짝 / 홀) / (홀 / 짝 / 홀) 

의 형태가 반복되는 것을 확인할 수 있다.

따라서 피보나치 수열에서 짝수인 항은 항상 항 번호가 $3$으로 나누었을 때 나머지가 $2$인 항이다.

즉, 우리가 구해야 하는 짝수 피보나치 항은

$F_2, F_5, F_8, F_{11}, ...$

과 같이 나타낼 수 있다.

따라서 항 번호가 $3k+2$인 일반항 $F_{3k+2}$를 이용하여 짝수 피보나치 항들의 규칙을 찾아보려고 한다.

<규칙 찾기>

$F_{3k+1} = F_{3k} + F_{3k-1}$

$F_{3k+2} = F_{3k+1} + F_{3k}$

$F_{3k+3} = F_{3k+2} + F_{3k+1}$

로 설정을 해 주었고,

$F_{3k+4} = F_{3k+3} + F_{3k+2}$

$F_{3k+5} = F_{3k+4} + F_{3k+3}$

이고, 우리가 $F_{3k+5}$에 대해서 정의를 해 주어야 한다고 생각을 하였다.

먼저, $$F_{3k+5} = F_{3k+4} + F_{3k+3} $$

이고, $F_{3k+4} = F_{3k+3} + F_{3k+2}$이므로

$$F_{3k+5} = 2F_{3k+3} + F_{3k+2} $$

이다. 또한 $F_{3k+3} = F_{3k+2} + F_{3k+1}$이므로

$$ F_{3k+5}= 2(F_{3k+2} + F_{3k+1}) + F_{3k+2} $$

$$ = 3F_{3k+2} + 2F_{3k+1} $$

### 3번
어떤 자연수 $n$이 $i$로 나누어떨어진다는 것은

$$
n \div i
$$

의 나머지가 $0$이라는 의미이다.

즉,

$$
n \bmod i = 0
$$

이면 $i$는 $n$의 약수이다.

이를 식으로 나타내면 어떤 자연수 $k$에 대하여

$$
n = ik
$$

로 나타낼 수 있다.

따라서 $i$가 $n$의 약수인지 확인하기 위해서는

$$
n \bmod i = 0
$$

인지 확인하면 된다.

또한 $n=ik$일 때 두 약수 $i$와 $k$의 곱이 $n$이므로, 두 수 중 하나는 반드시 $\sqrt n$ 이하이다.

따라서 $n$의 약수를 찾을 때는

$$
i^2 \le n
$$

즉,

$$
i \le \sqrt n
$$

인 범위까지만 확인하면 된다.
